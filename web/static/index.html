BM-RAG

Multi-agent RAG that decides where a phase change material belongs in a building wall, then checks the answer against EnergyPlus.

Runs replayed with no API key. Recorded runs are single real runs that show how the system works; samples marked synthetic use invented data. Neither is an evaluation.

Live mode is off because each run spends API credit. It needs the agent environment, the knowledge-graph data and Neo4j.

.venv/Scripts/python.exe -X utf8 web/server.py --live

Unedited scenarios are scored against their EnergyPlus optimum.
